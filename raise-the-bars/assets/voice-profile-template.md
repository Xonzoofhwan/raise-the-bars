# 보이스 프로파일: {제품 이름}

이 파일 하나로 스킬이 매번 묻던 것을 대신한다.
**프로젝트 루트나 `docs/` 아래에** `voice-profile.md`로 저장하면 스킬이 찾아 읽는다.
그 두 곳만 찾으므로 다른 위치에 두면 발견되지 않는다.

**제목의 제품 이름을 반드시 채운다.** 스킬이 지금 요청과 같은 제품인지 확인하는
데 쓴다. 한 저장소에 여러 제품이 있으면 각 제품 폴더의 루트에 따로 둔다.
이름이 요청과 어긋나면 스킬이 값을 쓰지 않고 되묻는다.

**빈칸으로 두어도 된다.** 채워진 항목만 쓰고 나머지는 기본값을 쓴 뒤 무엇을
가정했는지 밝힌다. 값이 바뀌면 이 파일만 고치면 된다.

## 2. 어떤 목소리로 쓰는가 (축 5개)

모르겠으면 비워 둔다. 기본값이 적용되고, 결과물을 보며 조정하는 편이 빠르다.
각 축의 뜻은 `references/profile.md`에 있다.

| 축 | 값 | 기본값 | 고르는 법 |
|---|---|---|---|
| **종결** | | 해요체 | 해요체 / 합니다체 / 명사형 중 택1, 중간 없음 |
| **경어** | | 낮음 | 낮음(기본 존댓말) / 중간(호칭·의문형에 높임) / 높음(극존칭) |
| **용어** | | 최소 | 최소 / 중간 / 적극. 위에 적은 도메인 용어가 있으면 적극 |
| **공감** | | 중간 | 낮음(사실만) / 중간 / 높음 |
| **밀도** | | 간결 | 간결 / 중간 / 상세 |

**경어는 어느 값이든 존댓말이다.** 낮음이 반말이라는 뜻이 아니라,
'~시'나 '계시다' 같은 높임을 쓰지 않는 기본 존댓말이라는 뜻이다.

**민감 상황에서 높임을 한 단계 올릴까요?** (탈퇴·삭제·에러·정책 안내 등)

## 채우는 순서

전부 한 번에 채우지 않아도 된다. 갈림이 큰 것부터 셋만 채우면 시작할 수 있다.

1. **타깃 사용자**와 그들이 쓰는 도메인 용어. 용어 축이 여기서 갈린다
2. **종결**. 가장 눈에 띄는 차이다
3. **경어**. 기본 존댓말인가, 호칭에 높임을 유지하는가, 극존칭인가

나머지는 기본값으로 시작해 결과물을 보며 조정한다.
